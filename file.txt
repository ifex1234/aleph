6. App Installer Size (after 3-phase sqlite-vec build)
-------------------------------------------------------
- Old 7-phase (no vec): installer ~150-200MB / installed ~350MB
- A) Vec bundled + model BYO (RECOMMENDED for NG): aleph.db ~195MB (72MB +122MB vec0) -> installer ~280-320MB / installed ~650MB +571MB after first run
- B) Fully bundled offline: +571MB model -> installer ~580-680MB / installed ~1.1GB
- e5-small-multilingual (384d, 120MB model) alternative: installer ~380-420MB

7. Affordability Recommendation for Nigeria
-------------------------------------------
- Ship Whisper as default Free tier (₦0, offline)
- Keep Deepgram as Pro BYO tier: church enters own API key, consumes own $200 free then ₦1,120/sermon
- Charge one-time app license ₦25k-₦50k (not SaaS per-minute) - avoids FX risk
- Data cost reference: ₦1,120 ~ 2-3GB MTN data (₦1,500) - affordable for mid-size churches
