Aleph supports two STT engines, and you can swap between them at runtime
from Settings → STT. They map cleanly to two different operating
modes: zero-marginal-cost local inference, or offload-to-the-cloud
streaming.

## Option 1: Whisper (recommended for most installs)

The local engine shells out to the `whisper-cli` binary from
[`whisper.cpp`](https://github.com/ggml-org/whisper.cpp), feeding it short
audio windows as you preach. It needs two files: the binary and a GGML
model (`ggml-large-v3-turbo-q8_0.bin`, ~394 MB from Hugging Face).

### Installed app

Every installer now bundles the CLI — open Settings → STT and pick
**Whisper**. (On older macOS/Linux builds that predate bundling, provide
the binary yourself: `brew install whisper-cpp` and copy `whisper-cli`
into `sdk/whisper/macos/`, or build from source into
`sdk/whisper/linux/` — or simply point at any copy with
`export ALEPH_WHISPER_BIN=/path/to/whisper-cli`.)

### Building from source

From the repo root, run both scripts (each skips work that's already done,
so re-running is safe):

```bash
bun run download:whisper-bin   # CLI binary (auto-downloads on Windows)
bun run download:whisper       # model file → models/whisper/
```

### How the app finds things

The binary resolves by first match: `$ALEPH_WHISPER_BIN` →
bundled resources → `sdk/whisper/&lt;platform&gt;/`
→ `/opt/homebrew/bin/whisper-cli`, `/usr/local/bin/whisper-cli`.
The model resolves similarly via `$ALEPH_WHISPER_MODEL`, preferring
`ggml-large-v3-turbo-q8_0.bin` — but any `ggml-*.bin` you drop into
`models/whisper/` works, so smaller models are a legitimate trade of
accuracy for speed on modest hardware.

<Callout title="Missing pieces surface in the UI" type="info">
If the binary or model is absent, starting transcription fails with an
actionable error telling you exactly which command to run — check the
status indicator under the STT picker.
</Callout>

## Option 2: Deepgram

### 1. Get an API key

Sign up at [deepgram.com](https://deepgram.com/) and copy your API key.
Their $200 starter credit covers roughly 273 two-hour sermons.

### 2. Add it in the app

Open Settings → STT, paste the key, and choose **Deepgram**. (Developers
running from source can use `DEEPGRAM_API_KEY` in `.env` instead.)

The status indicator shows WebSocket health in real time; if it falls back
to REST, you'll see that labeled too.

## Switching engines at runtime

Both engines feed the same transcript stream, so you can switch without
restarting the session. The active translation, sermon context,
and queue state are preserved across the swap.

## Comparing the two

| | Whisper (local) | Deepgram (cloud) |
| --- | --- | --- |
| API cost | Free | Per-minute billing (your key) |
| Internet required | No, after the one-time downloads | Yes (WebSocket) |
| Setup cost | ~400 MB model download | Instant |
| Long-form accuracy | Good | Excellent |
| Punctuation | Decent | Excellent |
| Works offline | Yes | No |

Latency depends heavily on hardware and network conditions, so we
don't publish a single number — Whisper benefits from any GPU/Metal
acceleration on the machine, and Deepgram is bounded by the
round-trip to its nearest region. Pick whichever fits your install:
Whisper for the no-cost local path, Deepgram for the lowest latency
and best transcription quality on a reliable network.
